# Baseline (pre-hackathon)

These files were written on 2026-10-17, before NEAR HACKATHON opened on 2026-10-19.
They come from a private prototype that settled VND to a VietQR code through the
Gaian payments API, paid by an AI agent over x402 on Stellar and Base testnets.

They are copied here unchanged so the diff between the tags `pre-hackathon` and
`hackathon-submission` shows only the work done during the hackathon.

One value was changed on copy: the demo fee rate in `src/config.ts` is a round 1%,
so no real price appears in this repository.
